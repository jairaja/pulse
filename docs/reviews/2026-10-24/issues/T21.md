# [Feature] Multilingual question suggestions and pre-publication review workflow

Start with debounced/cancelable indexed lexical/full-text/trigram/prefix retrieval over public Brewing/live/Past Results. Test language-specific normalization/tokenization and negation/paraphrases; semantic AI is a later measured option, not a per-keystroke default. Suggestions route to the exact highlighted screen and retain draft/back context. Exact active duplicates need transactional protection; near matches suggest rather than auto-block, and historical questions can repeat as new dated occurrences.

Before public upvotes/sharing, apply format/abuse checks and asynchronous AI triage with durable Pending, provider timeout/retry, uncertain-human-review, same-slot edit/appeal and strict API-cost/rate controls. One UTC-day submission slot is reserved at accepted intake, not by typing or cancel. Midnight eligibility uses published_at, never retroactively includes post-boundary publication. Measure multilingual false-positive/negative quality before rollout; no real-time moderation SLA is assumed. See point 21.
